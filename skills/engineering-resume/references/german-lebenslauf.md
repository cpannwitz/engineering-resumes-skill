# German CV (Lebenslauf) rules

Used when the CV is written in German or targets a German-speaking employer (see "Choosing the
rule set" in `SKILL.md`). Practical guidance, not legal advice.

**If the `berlin-job-search` skill is installed, read its
`references/applications-germany.md` first** — it is the primary source for German application
conventions (Lebenslauf, Anschreiben, submission, Arbeitszeugnis). This file is the fallback and
lists how the wiki's English rules change for German CVs.

## What still applies from the English rules

Everything about *content quality*: impact over duties, best content first, tailoring,
integration over parts lists, no filler adjectives, no invented numbers (`bullets.md`), skills
grouped and backed by bullets (`sections.md` → Skills), readable single-column layout, no
graphics or skill bars, no justified text, proofreading.

## What changes

| Topic | English rule (wiki) | German CV |
|---|---|---|
| Length | 1 page (2 for senior) | 1–2 pages is normal; 3 only for long academic/senior careers |
| Layout | Dates right-aligned | Tabular layout with dates in a narrow **left** column is the convention; right-aligned dates are fine for international/tech employers |
| Dates | `Mar 2021 – Present` | `03/2021 – heute` (MM/YYYY, en dash, "heute"); all dates in one format |
| Header | Name + email; phone, city, LinkedIn optional | Name, target role/title line, email, phone, city (full street address optional, more traditional), LinkedIn and/or XING, GitHub |
| Photo | Never | Optional, not required. Common at traditional employers (Mittelstand, public sector, corporate); usually omitted for international tech. Professional headshot only; user decides |
| Personal data | Leave out (bias) | Birth date, nationality optional; marital status, religion, children: leave out. Work permit status if relevant (e.g. "Blaue Karte EU", "unbefristete Arbeitserlaubnis") |
| Summary | Only senior/career change | A 2–3 line **Kurzprofil** under the header is common and acceptable |
| Section names | Experience, Education, Skills | Berufserfahrung, Ausbildung (or Studium & Ausbildung), Kenntnisse (or Fachkenntnisse / IT-Kenntnisse), Sprachen, Projekte, optional Weiterbildung / Zertifikate, Ehrenamt |
| Education | Graduation date only, no start date | Date range (`10/2012 – 09/2016`), degree (keep original name, e.g. "B.Sc. Informatik"), institution, city, optional final grade (Abschlussnote) and thesis topic. Abitur only early in the career |
| Studies without degree | Omit | Keep them in the timeline so there is no gap: "Studium Medieninformatik (ohne Abschluss), TU Dresden" — compact, at the end of Ausbildung, never worded as a degree |
| Languages | Usually omitted | Always a section: Deutsch (Muttersprache), Englisch (C1) — CEFR levels A1–C2 |
| Phone/location | Possibly biasing | Expected |
| Ending | — | Ort, Datum and signature is traditional; optional and increasingly rare for online applications |
| Gaps | — | German readers notice gaps; give a short neutral label (Elternzeit, Weiterbildung, Sabbatical) |

## German bullet style

- Pick one style and keep it for the whole CV:
  - **Verb in past tense, no pronoun:** "Entwickelte eine Event-Pipeline mit Kafka, wodurch die
    Verarbeitungszeit um 60 % sank"
  - **Nominal style:** "Entwicklung einer Event-Pipeline mit Kafka; Verarbeitungszeit −60 %"
- German number formatting: `60 %` (space before %), `1.200` thousands separator, `2,5` decimals.
- Keep established English tech terms (Deployment, Pull Request, Microservices); don't force
  translations. Keep original English job titles if that is what the contract said.
- Weak verbs to avoid: "unterstützte bei", "war zuständig für", "wirkte mit", "half".
- Same honesty rule: no invented metrics; ask or describe scope instead.

## Files

- File name like `Vorname-Nachname-Lebenslauf.pdf`; selectable text; no tracked changes or
  hidden layers. When the employer wants one PDF, typical order is Anschreiben → Lebenslauf →
  Zeugnisse (defer to berlin-job-search for the full application package).
